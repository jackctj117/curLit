# Semiconductors

Not a commodity in the OANDA sense but the supply-chain node the system watches most densely. Leading-edge logic is concentrated in Taiwan ([[TSM]]) and lithography in a single Dutch supplier ([[ASML]]); the tradable expression runs through indices [[NAS100_USD]] and the chip ETFs [[SOXX]], [[SMH]], and single names [[AVGO]], [[QCOM]], [[AMAT]], [[LRCX]], [[KLAC]]. A [[Taiwan Strait]] event is simultaneously a chip-supply shock and a broad risk-off move. Export-control escalation ties it to [[sanctions_trade]] via [[NVDA]] and [[AMD]]. This is the core of [[taiwan_semiconductor]].
